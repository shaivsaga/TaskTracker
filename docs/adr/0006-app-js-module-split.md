# 6. app.js split into ES modules

**Decision.** `app.js` (3,428 lines) is split into ES modules under `js/`, with no bundler and no new dependency (ADR 4 stands): `state.js` (the one mutable `state` object), `dom.js` (the element cache and `cacheDom()`), `util.js` (shared helpers, storage keys, API constants) and nine feature modules - `calendar`, `quick-add`, `tour`, `settings`, `nav`, `transfer`, `announcements`, `publish`, `tasks`. `logic.js` is unchanged and still loads first. `app.js` keeps the bootstrap: `start()`, `checkAdmin`, `loadPublished`, `cacheDom()`, the `init()` wiring and the listeners no module owns (664 lines at the end of the split).

**Why.** The one file had no automated coverage of its own, and a region's dependencies were visible only by reading all of it. Two rules made the split safe: state that several regions reassign lives on the exported `state` object (a module-level `let` reassigned from another file throws `Assignment to constant variable`), and every module exports `init(deps)` instead of reading bare globals, so each dependency is named at its call site. Listeners register inside `init()`, in their original source order, at the call site that replaces the region's first top-level statement - the Escape chain (due picker capture, dialog, popover, overlays) depends on that order.

**Cost.**
- A moved symbol is imported or reached through its module object, never named bare. Slice 2.1 left eight bare reads of deleted bindings that no golden could reach, so `tests/module-state.test.js` enforces the rule in the js-tests job.
- Modules under `js/` are imported without `?v=`. The deploy stamper rewrites only `./logic.js?v=` in app.js and the stamped links in `index.html`; extending it was out of scope, and a module's own `?v=` would otherwise reach production unstamped. Residual risk: `js/*.js` is served by `location /` with ETag/Last-Modified and no `Cache-Control`, so a browser may reuse a cached module across a deploy. The fix is one line in the workflow's sed (plus `js/*.js` in the STALE grep) or `Cache-Control: no-cache` for `/js/` in nginx.
- `logic.js`'s header said it held the natural-language quick-add parsers. It never did: `parseQuickAdd`/`quickWords` have always been app.js-local, and now live in `js/quick-add.js`.
- `js/tasks.js` exports more names than the other modules read (56 at the tip of the split); trimming the list to what is used would mean rewriting the intermediate commits, so it is left as a follow-up with no behavioural effect.

**Status.** Executed on branch `overnight/split`; `docs/p6-architecture-findings.md` section 4 lists the modules and the CI constraint.
