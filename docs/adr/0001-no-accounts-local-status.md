# 1. No accounts, status stays on the device

**Decision.** Classmates have no accounts. Each person's status (Not started, In progress, Done) is stored in their own browser and never sent to the server.

**Why.** Privacy first: the President cannot see who has done what, and there is nothing to leak. No sign-up also means no friction for a class.

**Cost.** Progress does not follow a person to a new device, and clearing site data erases it. Transfer (QR code or link) is the workaround.
